КРАТКОЕ ОПИСАНИЕ
----------------
Учебный проект на Django для каталога туров, регистрации туристов,
бронирования даты и времени, а также отзывов о завершённых поездках.

Запуск локального сайта:
    http://127.0.0.1:8000/tours/

Административная панель:
    http://127.0.0.1:8000/admin/


ПРИЛОЖЕНИЕ TOURS
----------------
Основные модели проекта:

TouristProfile
    Дополнительные данные туриста, включая телефон.
    Связь с пользователем Django: один-к-одному (OneToOneField).
    У одного пользователя может быть один профиль туриста.

TourCategory
    Категория активности. Примеры: «Конный», «Пеший», «Мото».

Tour
    Тур с названием, описанием, длительностью и ценой.
    Связь с категориями: многие-ко-многим (ManyToManyField).
    У тура может быть несколько категорий, а одна категория может
    назначаться нескольким турам.

Booking
    Бронирование тура туристом на определённую дату и время.
    Связь пользователя с бронированиями: один-ко-многим (ForeignKey).
    Связь тура с бронированиями: один-ко-многим (ForeignKey).
    Ограничение базы данных не позволяет одному туристу создать более
    одного бронирования на одинаковую дату и время — даже для разных туров.

Review
    Комментарий туриста о туре.
    Связь пользователя и тура с комментариями: один-ко-многим (ForeignKey).
    Отзыв разрешён только туристу, который уже посетил тур.
    Турист может оставить несколько отзывов о завершённом туре.


РАБОТА С ПРОЕКТОМ
-----------------
Откройте PowerShell в папке проекта:

    cd "C:\Users\user\Desktop\Django Lb5-6"

Установите зависимости:

    python -m pip install -r requirements.txt

Примените миграции базы данных:

    python manage.py migrate

Создайте администратора (для входа в /admin/):

    python manage.py createsuperuser

Запустите локальный сервер:

    python manage.py runserver

Добавляйте и редактируйте туры и категории через административную панель.


ТЕСТИРОВАНИЕ
------------
Запустить все автоматические тесты:

    python manage.py test

Проверить настройки Django:

    python manage.py check

Проверить, что миграции моделей актуальны:

    python manage.py makemigrations --check --dry-run

Тестами проверяются страницы каталога и тура, регистрация, вход и выход,
сохранение и ограничения бронирований, отзывы, категории и связи моделей.
